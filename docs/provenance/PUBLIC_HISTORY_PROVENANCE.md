## Verifying frozen commit provenance

Run the public-history adapter from the repository root:

```sh
python scripts/verify_public_loading_kernel_freeze.py --metadata-only
```

The original verifier is itself checksum-pinned and remains unchanged. The
adapter uses `public-commit-map.tsv` only to resolve the four historical Git
commit fields, verifies that their mapped public commits exist, and adds
`commit_resolution` to the successful JSON report. Each entry reports
`original_sha` and `public_sha`; existing historical-SHA report fields retain
their original values. Missing mappings and missing public commits are errors.
Artifact checksums and other identity hashes are never translated.

All original artifact, label, replay and path checks still run. The excluded
digitised reference inputs are not restored by this adapter; the full verifier
still reports them as missing when they are unavailable. Commit resolution alone
is not a successful full evidence verification. No results are regenerated by
`--metadata-only`.
